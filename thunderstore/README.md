# BetterShop

《挺进地牢》商店优化模组 / Enter the Gungeon Shop Improvement Mod.

This mod aims to improve the shop experience by ensuring guaranteed item types and adding more NPC encounters throughout your run.

## Features / 功能特性

### 1. 商店保底 (Guaranteed Shop Items)

- **每层的老板店（Bello's Shop）现在至少会出售一把枪和一个被动/主动道具。**
- 再也不用担心由于脸黑或者隐藏属性导致商店里全是红心和护甲了！
- Shops are now guaranteed to sell at least one gun and one item (passive/active), preventing situations where only consumables are available.

### 2. 额外 NPC 生成 (Extra NPCs)

- **除了第六层（枪弹地狱）和第五层（锻造室）外，每一层都会额外生成一个 NPC。**
- 增加你在冒险途中遇到各种特色商人（如钥匙商人、多卖商人、诅咒商人等）的几率。
- An extra NPC will spawn on every floor (except the Forge and Bullet Hell), increasing your chances of finding special merchants.

### 3. 枪弹地狱特殊商人 (Bullet Hell Merchant)

- **在第六层（枪弹地狱）必定会生成一个特殊的“地狱商人”。**
- 由于第六层默认没有商店，这个额外的商人能让你在最终决战前有机会补给或挥霍多余的弹壳。
- A special merchant will always spawn in Bullet Hell (Floor 6), allowing you to spend your hard-earned casings before the final battles.

## Installation / 安装说明

**推荐安装方式 (Recommended):**

- 使用 **Thunderstore Mod Manager** 或 **r2modman** 一键安装。

**手动安装 (Manual Installation):**

1. 确保已安装 [BepInExPack_EtG](https://thunderstore.io/c/enter-the-gungeon/p/BepInEx/BepInExPack_EtG/)。
2. 确保已安装前置依赖 [Alexandria](https://thunderstore.io/c/enter-the-gungeon/p/Alexandria/Alexandria/)。
3. 下载本模组的 `.zip` 压缩包。
4. 将解压出来的 `BetterShop` 文件夹直接放入游戏目录下的 `BepInEx/plugins/` 文件夹中。

## Compatibility / 兼容性

- 需要 BepInEx 和 Alexandria 前置。
- 理论上兼容大部分不修改商店生成逻辑的模组。
